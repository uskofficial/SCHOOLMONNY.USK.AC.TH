เข้าสู่ระบบแอดมิน

เพิ่มปีการศึกษา

เว็บไซต์ต้องอนุญาตให้ฝังใน iframe และไม่ใช่ลิงก์ของหน้าหลักนี้

ตั้งค่าก่อนใช้งานครั้งแรก

  1. เปิด Firebase Console → โปรเจกต์ schoolmonnyusk → Authentication → Sign-in method → เปิด Email/Password
  2. เพิ่มบัญชีผู้ดูแลใน Authentication → Users และคัดลอก UID (ไม่มีการสมัครแอดมินจากหน้าเว็บ)
  3. Realtime Database → Data: เพิ่ม portalAdmins/UID_ของผู้ดูแล เป็นค่า boolean true โดยทำผ่าน Console เท่านั้น
  4. ตั้งค่า Rules ตามด้านล่าง หากฐานข้อมูลนี้มีระบบเดิม ให้รวมเฉพาะ portalAdmins และ schoolPortal เข้ากับกฎเดิม และตรวจว่า root ไม่มีสิทธิ์อ่าน/เขียนสาธารณะที่ทับกฎลูก ห้ามลบข้อมูลหรือกฎของระบบอื่น
  5. เพิ่มโดเมนที่ใช้โฮสต์ใน Authentication → Settings → Authorized domains และอัปโหลดไฟล์นี้เป็น index.html บน HTTPS
  6. เข้าสู่ระบบแล้วเพิ่มลิงก์ของแต่ละภาคเรียน ทดสอบด้วยบัญชีแอดมินและหน้าต่างที่ไม่ได้ล็อกอิน

ไม่สามารถตั้งค่าฝั่ง Firebase จาก API key เพียงอย่างเดียวได้ คู่มือนี้ต้องดำเนินการโดยเจ้าของโปรเจกต์

ลิงก์ปีการศึกษาจะอยู่ใน schoolPortal/terms โดยไม่แก้ข้อมูลการชำระเงินเดิม รีเฟรชจะกลับสู่ภาคเรียนที่เลือกไว้ล่าสุดในแท็บนั้น (ไม่สามารถจำหน้าภายในเว็บไซต์ต่างโดเมนได้) ปุ่มกลับหน้าเริ่มต้นจะล้างการเลือก
